# 🧠 Sistema de Orientação de Carreira em Tecnologia com IA (Agent 1 + Agent 2)

Este repositório contém um sistema completo com **dois agentes de IA** que trabalham juntos para ajudar pessoas a encontrarem o melhor caminho na área de tecnologia — desde descobrir a carreira ideal até seguir um roadmap personalizado de estudos, com planilhas, projetos de portfólio e preparação para entrevistas.

---

## 📌 Sobre o Sistema

Este sistema possui dois agentes conectados:

| Agente                               | Função                                                                 |
| ------------------------------------ | ---------------------------------------------------------------------- |
| **Agent 1 – Entrevistador**          | Descobre o perfil profissional e recomenda 3 carreiras                 |
| **Agent 2 – Planejador de Carreira** | Gera um plano completo de estudos e portfólio para a carreira escolhida |

Juntos, eles formam um fluxo completo de **descoberta → escolha → plano de ação → execução prática**.

---

## 🚀 Como Funciona

### **1️⃣ Agent 1 – Entrevistador de Carreira**

O Agent 1 conduz uma entrevista de 7 perguntas (sempre 1 por vez) para entender:

* Interesses e motivações  
* Experiência atual  
* Disponibilidade de estudo  
* Preferências de trabalho  
* Objetivos profissionais  

Após coletar tudo, ele analisa e recomenda as 3 melhores carreiras, com:

* Por que combina  
* Vantagens  
* Desafios  
* Visão do mercado  

Quando o usuário escolhe, ele envia as informações para o Agent 2.

---

### **2️⃣ Agent 2 – Planejador Personalizado de Carreira**

Após receber os dados do Agent 1, o Agent 2 cria um plano completo, incluindo:

✅ Visão do dia a dia da carreira  
✅ Mapa de skills essenciais e complementares  
✅ Roadmap de estudos de **120 dias** (em formato de planilha Excel)  
✅ Projeto de portfólio com escopo e critérios de aceitação  
✅ Roteiro de entrevistas com perguntas e respostas simuladas  
✅ Trilha DIO recomendada para prática guiada  

O plano é personalizado com base em:

* Horas semanais disponíveis  
* Experiência  
* Objetivo (primeiro emprego, transição ou crescimento)  
* Preferências (pessoas/dados/código)  
* Interesses técnicos (Python, SQL, GitHub, Jupyter, etc.)

## 🔥 Diferenciais do Sistema

* Roadmap detalhado em **formato de planilha Excel** para acompanhamento semanal  
* Integração com **GitHub** para publicação de projetos e portfólio  
* Sugestão de **cursos gratuitos no YouTube** para cada módulo (Python, SQL, Git/GitHub, Jupyter)  
* Preparação prática para entrevistas técnicas e comportamentais
